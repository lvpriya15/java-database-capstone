# User Stories — Smart Clinic Management System

## Admin
- As an Admin, I want to log in securely so that I can manage the clinic system.
- As an Admin, I want to add doctors with their specialty, contact details and available times so that patients can find them.
- As an Admin, I want to view and manage doctor information so that clinic provider data remains accurate.

## Doctor
- As a Doctor, I want to log in securely so that only authorized doctors can access patient information.
- As a Doctor, I want to view my appointments for a selected date so that I can manage my daily schedule.
- As a Doctor, I want to view patient details associated with my appointments so that I can provide care.
- As a Doctor, I want to create prescriptions so that treatment instructions can be recorded.

## Patient
- As a Patient, I want to log in securely so that my medical information is protected.
- As a Patient, I want to search doctors by name or specialty and available time so that I can choose a suitable provider.
- As a Patient, I want to view available appointment slots so that I can book an appointment.
- As a Patient, I want to view my booked appointments so that I can keep track of my visits.

## Reporting
- As a clinic administrator, I want daily appointment reports by doctor so that schedules can be reviewed.
- As a clinic administrator, I want monthly and yearly patient-volume reports so that doctor workload can be analyzed.
